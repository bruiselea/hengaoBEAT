# 変顔BEAT対決ができるまで

## 出発点：MacBookをアコーディオンにする

このプロジェクトの出発点は、MacBookそのものを楽器にするアイデアでした。

MacBookの開閉をアコーディオンの蛇腹に見立て、キーボードで音を鳴らす。さらにスマートフォンも別の楽器として参加させ、MacBookとスマートフォンを使って複数人でセッションできるアプリを目指しました。

画面の中だけで完結する音楽アプリではなく、身近なデバイスの形や動きをそのまま演奏に変えることが最初のコンセプトでした。

## 最初の壁：デバイス間の同期

MacBookとスマートフォンをリアルタイムにつなぎ、同じビートの上でセッションさせようとしました。しかし、通信遅延やタイミングのずれが大きく、演奏として気持ちよく成立するレベルまで同期精度を上げることができませんでした。

音楽体験では、ほんのわずかな遅延も違和感になります。機能として接続できても、セッションとして楽しいとは限らないことが分かりました。

## 方向転換：スマートフォン単体の楽器へ

同期問題を避けるため、いったんMacBookとの連携を外し、スマートフォン単体で遊べる楽器へ切り替えました。

動作は安定しましたが、「スマートフォンから音が鳴る」だけでは、デモを見た瞬間に伝わる驚きや、このプロジェクトならではの強い印象が足りませんでした。

技術的に動くことと、人前で体験したくなることの間に、まだ距離がありました。

## 転機：顔そのものを楽器にする

そこで生まれたのが、変顔で音を鳴らすアイデアです。

- 口を大きく開くと **KICK**
- ニヤッと笑うと **SNARE**
- 眉を上げると **HI-HAT**

顔の動きなら、特別なセンサーや説明がなくても、見た瞬間に何をしているか伝わります。演奏者本人だけでなく、周囲で見ている人も楽しめます。

さらに、単に変顔で音を出すだけではなく、二人が演奏し、その完成度をAI審査員が採点する「変顔BEAT対決」へ発展しました。音楽、ゲーム、変顔という分かりやすい要素を組み合わせることで、ようやくこのプロジェクト独自の体験が見えてきました。

## 現在地

現在のプロトタイプでは、スマートフォンのカメラで顔を認識し、口・笑顔・眉の動きを3種類のドラム音に変換できます。

PLAYER 1とPLAYER 2が順番に16ビートを演奏し、次の4項目からスコアを算出します。

- グルーヴ
- 変顔力
- 技の多彩さ
- パワー

公開版は以下からプレイできます。

**[変顔BEAT対決をプレイする](https://hengao-beat-battle.natuna.chatgpt.site/?v=2)**

ただし、現時点では完成形からはまだ遠いプロトタイプです。現在の二人対戦は、一台の端末を交代で使う形式で、採点も端末内の顔認識結果をもとにしたルールベースの判定です。

## これから実現したいこと

次の目標は、本当の意味でのリアルタイム変顔ビートバトルです。

### 1. 二台のスマートフォンによるリアルタイム対戦

PLAYER 1とPLAYER 2が、それぞれ自分のスマートフォンから同時に参加できるようにします。ルーム作成、参加コード、カウントイン、演奏開始を同期し、離れた場所からでも対戦できる仕組みを目指します。

### 2. PC観戦画面

PC画面にPLAYER 1とPLAYER 2の映像を同時に表示し、ステージや配信で観客が二人の変顔と演奏を比較できるようにします。

### 3. リアルタイムスコア表示

グルーヴ、変顔力、多彩さ、パワーの変化を演奏中にリアルタイムで可視化します。最後に突然結果が出るのではなく、どちらがリードしているか、どの変顔でスコアが伸びたかを観客にも伝えます。

### 4. 対戦としての完成度向上

採点ロジック、音の種類、ビートパターン、コンボ、観客投票などを追加し、毎回違う展開が生まれるゲームへ発展させます。

## このプロジェクトで分かったこと

このプロジェクトは、最初のアイデアをそのまま完成させたものではありません。

同期がうまくいかず、構成を小さくし、インパクト不足に気づき、もう一度コンセプトを作り直しました。その試行錯誤の結果、「デバイスを楽器にする」という最初の発想は、「自分の顔を楽器にする」という、より直接的で伝わりやすい体験へ変化しました。

完成していないからこそ、ここからリアルタイム対戦と観戦体験まで発展させる余地があります。
